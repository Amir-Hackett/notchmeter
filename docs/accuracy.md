## The promise

Every number Notchmeter shows is either a figure the vendor returned or an estimate built from a rule written down on this page. For each estimate this page will state which token buckets are read, which per-model prices and multipliers are applied, how duplicate lines are recognised and dropped, and exactly where the result is known to diverge from what the vendor bills, with a golden-transcript test suite in the repository pinning every rule so that a change in the numbers surfaces as a failing test rather than a surprise. Notchmeter will not show a number it cannot show its work for.
