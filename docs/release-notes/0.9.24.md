# Notchmeter 0.9.24

### Sessions

- **Drop a file on the notch and it lands in a session's prompt.** Drag a screenshot, a log or a PDF onto the rings and the panel opens; let go and the file's path is typed into the prompt of the session that is waiting on you, or else the newest one with a terminal, with `@` in front for Claude Code so the file is read into the turn. Drop it on a row to pick the session. A tmux pane, iTerm2, kitty and WezTerm take the text directly, on the Automation grant the jump already holds; Terminal, Ghostty and an editor get it on the clipboard with the jump, and the panel says *paste it with ⌘V*. Off with *Drop a file on the notch to hand it to a session* under Settings › Assistants › Sessions. Nothing is read from the file and nothing leaves the Mac ([docs/features.md](../features.md#drop-a-file-on-the-notch)).
