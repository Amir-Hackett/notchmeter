# Notchmeter 0.9.15

### Cursor in the notch

- A Cursor plan shows on its chat's row the moment it is created, with View Plan to open it in Cursor and Build while it is ready. Pressing Build titles the turn "Build: <plan>", and the plan's to-dos become the row's task list, marked building, then completed or cancelled.
- A Cursor row shows the chat's mode (Plan, Agent, Ask and the rest) and a Background chip for a background agent.
- A failed tool call, and whether you interrupted it, counts toward "May be stuck" for Cursor too. The compaction notice quotes the fill Cursor reports.

### Answering Cursor from the notch

Two switches on Cursor's page in Settings, both off until you turn them on:

- *Require notch approval for every command*: every shell command and MCP call Cursor runs waits for Run or Deny on the session's row. If nobody answers, Cursor shows its own prompt. Nothing runs on silence.
- *Mirror Cursor's cards*: Cursor's own Run prompt, its mode-switch card (Always ask, Skip, Switch) and a plan's View Plan / Build card appear on the row with Cursor's button labels, and the one you pick is pressed in Cursor. It needs the Accessibility permission, re-reads the card before each press, and presses nothing if the card changed.

### Numbers

- Cursor's usage events are read defensively: a count that is negative, not a number or too large to hold is dropped instead of crashing the read, and an event dated outside 2020 to 2100 is skipped.

### Diagnostics

- The report has a `cursor:` line: the installed Cursor version, and for sessions, plans, run approval, mode switch, Build and View Plan, where each comes from on this Mac (the hook, Cursor's own files, Accessibility, or only opening Cursor).
