# Notchmeter 0.9.15

### Cursor in the notch

- A Cursor plan shows on its chat's row the moment it is created, with View Plan to open it in Cursor and Build while it is ready. Pressing Build titles the turn "Build: <plan>", and the plan's to-dos become the row's task list, marked building, then completed or cancelled.
- A Cursor row shows the chat's mode (Plan, Ask, Debug and the rest) as of its latest prompt, and a Background chip for a background agent.
- A failed tool call, and whether you interrupted it, counts toward "May be stuck" for Cursor too. The compaction notice quotes the fill Cursor reports.

### Answering Cursor from the notch

Two switches on Cursor's page in Settings, both off until you turn them on:

- *Require notch approval for every command*: every shell command and MCP call Cursor runs waits for Allow or Deny on the session's row. *Answer in Cursor* hands one back to Cursor's own prompt, and so does a call nobody answers. Nothing runs on silence.
- *Mirror Cursor's cards*: Cursor's own Run prompt (Skip, Run) and its mode-switch card (Skip, Switch) appear on the row with Cursor's button labels, the Run card headed by the command it would run, and the one you pick is pressed in Cursor; the row's Build presses Build on the plan's card. It needs the Accessibility permission, re-reads the card before each press, and presses nothing if the card changed. Cursor's windows are read only while a Cursor chat is in a turn. While the switch is on, Cursor's editor shows Screen Reader Optimized unless `editor.accessibilitySupport` is off in Cursor's settings.

### Numbers

- Cursor's usage events are read defensively: a count that is negative, not a number or too large to hold is dropped instead of crashing the read, and an event dated outside 2020 to 2100 is skipped.

### Diagnostics

- The report has a `cursor:` line: the installed Cursor version, and for sessions, plans, run approval, mode switch, Build and View Plan, where each comes from on this Mac (the hook, Cursor's own files, Accessibility, or only opening Cursor).
