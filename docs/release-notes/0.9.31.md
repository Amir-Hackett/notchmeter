# Notchmeter 0.9.31

### Cursor

- **Cursor agents that nobody is watching stay off the Sessions card.** A `cursor-agent -p` started by a script, a server or a launch agent has no terminal or window. Each run is also a new conversation. Until now, each one showed up on the Sessions card as a row named after its folder. The row couldn't be opened and kept moving around the list. Before it sends anything from a Cursor agent, Notchmeter now checks whether there's a terminal or an app above that agent. If it finds neither, it doesn't show the agent. Chats in the Cursor app and `cursor-agent` run in a terminal show as before, and requests waiting for your decision still go through.
