Usage trackers for AI coding tools, in the MacBook notch

Notchmeter is one free, open-source Mac app that meters eight AI coding tools beside the MacBook notch — or on any screen edge — with a pace tick, a projection and the reset on every window, and an Advice strip that says what to do about the number. Every figure is the vendor's own or an estimate whose rule is written down, with its source and its date, in docs/accuracy.md.

An AI usage tracker for the Mac

What every meter has in common

The same rules apply to all eight tools, and each is written down with its source and its date in docs/accuracy.md.

A pace tick

Where an even burn would be right now, on every window that declares its length; a window without one shows its fraction and its reset and no tick.

A projection

“~67% left at reset” or “Runs out in 2h”, and a run-out range measured from your own last seven days once there is enough to measure.

A source label

Every window says whose figure it is: the vendor's, Claude Code's status line, a tool's last session file, or an estimate.

No sign-in

Each reading is borrowed from the tool that owns the account, on the login that tool already keeps on this Mac. Nothing is stored and nothing goes to a server of ours.

Which tools report spend

The Cost card carries one row per tool whose spend can be derived from something that tool publishes, and no row at all for one that cannot: not $0, because a zero says "this cost you nothing", and that would be a claim.

  • Claude Code and Codex: this Mac's transcripts and session rollouts, priced here at Anthropic's and OpenAI's published rates. An estimate, and labelled as one.
  • Cursor: the cost Cursor itself put on each event in its usage export. Nothing is priced here.
  • GitHub Copilot: GitHub's own count of the seat's AI credits, a cent each at GitHub's published rate.
  • OpenCode: on OpenCode Go, the Go page's published rates applied here to each turn's tokens; otherwise the cost OpenCode itself recorded, or a direct Anthropic or OpenAI model at that vendor's list rate; anything else is counted in tokens with no figure.
  • Gemini CLI, Antigravity and Kimi Code: no row. Google and Moonshot meter quota, not money, and publish nothing a rate could be applied to.

Questions

Do I need all eight tools installed?

No. Notchmeter meters whichever tools have a login on this Mac; switch the others off under Settings › Assistants and the strip shows what is left, with the rings giving their room to the ones you keep.

Does it track more than one account per tool?

It reads the login each tool keeps on this Mac, so it follows the account that tool is signed into. Switch accounts in Claude Code, Codex, Cursor, Gemini CLI, Kimi Code or your editor and the notch follows on its next read.

Which tools show a cost?

Claude Code and Codex, priced here from this Mac's transcripts and rollouts at the vendors' published rates and labelled as estimates; Cursor and GitHub Copilot, with the vendor's own figures; OpenCode, from the cost its own database recorded on each turn, or on OpenCode Go the Go page's rates applied here; and Gemini CLI, Antigravity and Kimi Code not at all, because Google and Moonshot meter quota rather than money. A tool that cannot report spend has no row, not a $0.

Does it tell me which tool to use?

When one tool's window is behind pace and another tool on a paid plan still has half of its own left, the Advice strip names it: “Codex has 78% of its weekly left.” It never names a free tier as the room to move to.

Where do the numbers come from?

From the vendor wherever the vendor publishes one, in the same read-only status request that vendor's own app or dashboard makes, and otherwise from a rule written down with its source and its date in docs/accuracy.md, pinned by tests. Notchmeter does not show a number it cannot show its work for.
