An AI usage tracker for the Mac, in the notch

Notchmeter is a free, open-source Mac app that meters five AI coding tools, Claude Code, Codex, Cursor, Antigravity / Gemini CLI and GitHub Copilot, beside the MacBook notch or on any screen edge. Every meter has a pace tick, a projection and its reset; an Advice strip says what to do about the number; and every figure is sourced, dated and tested, with the rule behind it written down in docs/accuracy.md. It never signs in anywhere, never stores a token and keeps no server.

The whole picture, on hover

Every meter shows a pace tick, where an even burn would be right now, a projection (“~67% left at reset” or “Runs out in 2h”) and the reset as a countdown or an exact time. The Cost card adds what your local Claude Code and Codex sessions would have cost at API list prices, and the dollars Cursor and GitHub Copilot themselves put on the month.

The Advice strip under it is worded as an instruction rather than a percentage: Opus weekly is 91%. Sonnet is 34%. Switch models, not tools. The rules are pure functions over every visible tool's live reading, and each is pinned by a test.

Press ⌘U for the Usage Dashboard: the week's spend by day and by assistant, every limit with how much a day lasts to its reset, and where the money went by model and by project.

The privacy model is the product

Notchmeter never signs in anywhere and never stores a token. It reads the login the vendor's own tool already put on this Mac, makes the one status read that tool itself makes, and passes it on to nobody.

What it does

  • One status read per tool, on that tool's own saved login
  • Reads your local Claude Code transcripts and Codex rollouts for the cost figures
  • Keeps everything on the Mac it runs on
  • Asks for Accessibility only if you choose the Auto layout

What it never does

  • No account, no sign-in, no cloud, no analytics
  • Never stores or forwards a token
  • Never sends a prompt, a transcript or a project path anywhere
  • Never probes an inference endpoint for rate-limit headers

Every request the app makes, what it names itself as, and where it stands against each vendor's terms: Who each request says it is, and the honest rest of it in the privacy policy.

Questions

Which AI tools does Notchmeter track?

Claude Code, Codex, Cursor, Antigravity and Gemini CLI, and GitHub Copilot: one ring each beside the notch, one card each in the panel, and one page each on this site saying what is shown and where it comes from. Switch off the ones you do not use and the rings give their room to the ones you keep.

Do I need to sign in or create an account?

No. Notchmeter never signs in anywhere. Each reading is borrowed from the tool that owns the account, on the login that tool already keeps on this Mac, in the same read-only status request the tool's own app or dashboard makes. It never refreshes or stores a token and has no server of its own.

Which Macs does it run on?

Any Mac on macOS 15 Sequoia or later, Apple silicon or Intel. On a MacBook with a notch the rings sit beside it; on any other Mac, or if you would rather, the same notch shape is cut into the left or right edge of the screen, there is a bar above the Dock, and a pill under the menu bar. There is no Windows or Linux version.

Is it really free?

Yes. The whole app is free, MIT licensed and open source, with no trial, no locked feature and no nag. You can pay what you want towards it, once, and nothing changes in the app either way.

How accurate are the figures?

The limits are the vendors' own figures, read from the same endpoints the vendors' own apps read, and every window says whose figure it is. The costs are estimates whose rules are written down with their sources and dates in docs/accuracy.md, pinned by a golden-transcript test suite; a tool whose spend cannot be honestly derived has no cost row rather than a $0. Notchmeter does not show a number it cannot show its work for.

What does it cost to run?

On an M5 Pro with a heavy Claude Code job in the background: 1.4% of one core over 60 seconds with the panel closed, 0.0% between cost scans, a 63 MB physical footprint, and nothing at all while the screen is locked, the displays are asleep or the Mac is. The method and the raw numbers are in docs/energy.md.
