Every macOS agent-notch app compared (2026)

At least ten apps now put coding agents in or beside the MacBook notch, every one of them released or updated this year. Notchmeter is one of them, and this page is ours, so read it with that in mind. It is written to be the fair one: every app below does something better than Notchmeter does, and its entry says what.

  • Published 24 September 2026
  • Tested on Notchmeter 0.9.0
  • Stars read from GitHub on 2026-09-24

The short answer

For the most agents, Vibe Island. For the most polish and choice of look, AgentNotch. For the biggest community and no setup, Vibe Notch. For a character that reacts to your agents, Notchi or Buddi. For nothing ever written to your agents' config, agent-notch. For Claude and Codex limits with a usage history you can share, CodexIsland. For figures you can audit, several vendors' limits side by side and advice about them, Notchmeter.

How this was put together. Star counts, licences and last-push dates are from GitHub's API on 24 September 2026; a licence is given as GitHub reports it, with the README's own claim where the two differ. Features are from each project's own README, site or changelog, read the same day. No two apps were run side by side for this page, so nothing here is a benchmark, and a feature missing from a project's own documentation is not proof it is missing from the app.

Each app, and where it beats Notchmeter

Vibe Notch (formerly Claude Island)

farouqaldori/vibe-notch. Claude Code sessions in a Dynamic Island-style overlay, with permission approvals and the full chat history rendered in the notch.

Where it beats Notchmeter: by far the largest community, and two other apps here, MioIsland and Buddi, started from its code. No setup at all. It shows a session's conversation, which Notchmeter deliberately does not.

Worth knowing: its README says it installs its hooks automatically on first launch and collects anonymous usage events with Mixpanel (app launched, session started). No push since 2026-04-20.

Notchi

sk-ruban/notchi. A notch companion for Claude Code and Codex: a pixel sprite per session that reacts to thinking, working, permission requests, compaction and errors, with session time, usage quota and 30 days of cost and tokens a click away.

Where it beats Notchmeter: personality, and a real community. A sprite per session says what each agent is doing at a glance, in a way a ring does not, and it is actively maintained.

Worth knowing: it installs its hooks on first launch. An optional mood feature sends your prompts to Anthropic or OpenAI for sentiment analysis, with an API key you paste in. It needs a MacBook with a notch.

MioIsland

MioMioOS/MioIsland. A Claude Code notch app, forked from Claude Island, with an iPhone companion called Code Light, status, session lists, approvals, buddies and 8-bit sound.

Where it beats Notchmeter: your sessions on your phone, with two-way sync and remote launch. Notchmeter has no phone app.

Worth knowing: its README states a non-commercial licence (CC BY-NC 4.0), which GitHub does not recognise as open source. The README is mostly images, in Chinese.

CodexIsland

ericjypark/codex-island. "Your AI usage limits, living in your notch": Claude Code's and Codex's 5-hour and weekly windows, local-log cost estimates, and a year of usage history.

Where it beats Notchmeter: it is the app closest to Notchmeter's own pitch, and it is moving fast (pushed the day this was written). Its usage history is a year-at-a-glance calendar kept in its own database, it makes a shareable usage card, it offers five chart styles, and it estimates OpenCode's cost as well.

Worth knowing: Claude and Codex only, and no sessions. Its README says the app is unsigned by Apple and its Homebrew cask removes the quarantine attribute. It reads credentials written by Claude Code or Claude Desktop.

agent-notch

realfishsam/agent-notch. "No hooks, no APIs, no accounts." A session is an agent process attached to a terminal, polled every three seconds; a mascot walks beside the notch while it works.

Where it beats Notchmeter: it never writes anything and needs no setup, and it is small enough to build from one Swift file. Its README is unusually honest about the cost of that design.

Worth knowing: Claude Code and Codex only, terminal sessions only, and no waiting detection. In its own words, the mascot "keeps walking for up to ~33 s … after a turn actually ends".

AgentNotch (AppGram)

AppGram/agentnotch. Real-time tool calls, tokens and estimated cost for Claude Code and Codex, received as OpenTelemetry on port 4318.

Where it beats Notchmeter: it sees every tool call as it happens, from the agents' own telemetry, without a hook in any settings file; you point the agent at it yourself.

Worth knowing: this is not the same product as agentnotch.app below, despite the name. Its README says MIT, but GitHub finds no licence file, and there has been no push since January.

Vibe Island

vibeisland.app. A notch panel for a very long list of agents: live status, approvals, answers to questions, plan review, and a jump back to the exact terminal tab, split pane or IDE window.

Where it beats Notchmeter: breadth, clearly. Its site lists 30 agents (its repository description says 25) and 20 terminals and IDEs. SSH remote monitoring is built in, where Notchmeter's needs a tunnel and a hook you set up yourself. It reviews full Markdown plans, and its 8-bit sounds can be replaced with your own packs. Its usage view covers Claude, Codex, Kimi, GLM and DeepSeek.

Worth knowing: closed source; $19.99 for one Mac with a year of updates, and a free trial. Its README says detected CLIs are set up automatically on first launch. It publishes its own comparison of the field, which is worth reading beside this one.

Buddi

talkvalue/Buddi. A home in the notch for Claude Code's buddy, built on boring.notch and Claude Island.

Where it beats Notchmeter: it is a whole notch utility, with a music player, calendar, file shelf and volume and brightness overlays beside the agent. It has eighteen buddy species, a chat view that can send messages back to Claude Code, and tmux and cmux support.

Worth knowing: Claude Code only, and it installs its hooks on first launch.

Claude Stats

1pitaph/claude-stats. A menu-bar stats app for AI coding work, with a notch island among many other modules.

Where it beats Notchmeter: scope. Dashboards, Git and GitHub views, daily reports, an iPhone and iPad companion through iCloud, an embedded terminal and a network debugger, and a Lite build for people who want less.

Worth knowing: it parses Claude Code and Codex logs today; the notch is one module, not the product.

AgentNotch (agentnotch.app)

agentnotch.app. "Every coding agent. One place to look." Sessions first, usage second, for Claude Code, Cursor, Codex, Kimi, OpenCode, Cowork, Antigravity, Pi and LM Studio, per its site.

Where it beats Notchmeter: it feels finished, and it lets you make it yours: a choice of panel colours and of how much desktop shows through, and a light Paper theme. Five distinct sounds for completions, questions, approvals, ready plans and other requests. A locally computed meter for the OpenCode Go plan, which publishes no usage endpoint. Anonymous feedback from inside the app, and a switch per display.

Worth knowing: closed source; $9.99 once, with a three-day trial that needs no card and a 14-day refund. Its site does not say how it reads sessions; its changelog records that its Live Prompts "can no longer overwrite your agent's configuration, and every write leaves a backup". Not the AppGram project above.

Notchmeter

Amir-Hackett/notchmeter. Usage meters for Claude Code, Codex, Cursor, Antigravity / Gemini CLI and GitHub Copilot, with sessions, answering from the notch, and advice about what to do next.

Where it is behind: one star, so very few people have looked at it. Fewer agents than Vibe Island or AgentNotch. No mascot, no phone app, and remote sessions need a tunnel you set up yourself.

What it does that we did not find in the others' own documentation:

  • A published accuracy document: every rule behind every figure, its primary source and date, and where it is known to differ from a bill, pinned by golden tests to nine decimal places.
  • Every window labelled with where its figure came from, and a tool that cannot derive spend shown as missing, never as $0.
  • Pace, measured drain and a run-out range from your own hours, with peak hours and a budget treated as a window.
  • Advice worded as instructions, including routing work across vendors.
  • Prompt-cache miss diagnostics, priced.
  • A command line tool, an MCP server, a local API, a Claude Code plugin, and CSV or JSON export.
  • Eleven languages, a VoiceOver label on every readout, and status never carried by colour alone.
  • Nothing written to your agents' config until you press a button (how).

The one that is not a notch app

If you work only in Claude's desktop app, you may not need any of these. Its documentation says it "sends an OS notification when a Code session finishes a task and you aren't currently viewing that session", lets you "filter sessions by status, project, or environment, and … group sessions by project", and shows your context and plan usage on a ring next to the model picker. It is first-party, and it costs nothing extra. What it does not do is meter Cursor, Copilot, Codex or Gemini, and that multi-vendor view is the ground every app on this page stands on.

Beyond the notch

A second group of apps tracks usage from the menu bar rather than the notch, among them ClaudeBar, coding-usage-bar, ClaudeUsageBar, Claude-Usage-Tracker and claude-code-monitor, and a third group browses past sessions, such as Claudoscope, Agent Sessions and so-agentbar. They were not reviewed for this page. Notchmeter's own pace projection and cost rules started from OpenUsage, which ports ccusage's transcript semantics, and both deserve a look.
