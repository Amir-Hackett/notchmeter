Why the app itself is free

Because you can already read the source

Notchmeter is MIT licensed and the whole repository is public. scripts/build.sh install builds it in twenty seconds. A licence check on top of that would be theatre, and it would tax the one thing an open tool needs, which is people trying it.

Because the interesting problem is the fleet

One developer already knows roughly what they are spending. A director with thirty engineers on five vendors does not, and no vendor's own dashboard tells them, because each one only sees its own half. That is worth paying for. A ring is not.

What Teams sends, exactly

The privacy model is the product. If the roll-up could see a prompt, it would be a monitoring tool, and no engineer would leave it switched on. So it cannot.

One document, per machine, per day
  • The date
  • A random machine id, minted at opt-in and resettable
  • An optional label you type
  • Per tool: the peak used fraction of each window, and its reset time
  • The day's cost estimate, split by model and token bucket
Never, by construction
  • No token, account id, email or hostname
  • No prompt, transcript or project path
  • No per-request rows, no timestamp finer than the day
  • No real-time view, no remote control, no blocking
  • A test asserts the outgoing document's keys against an allow-list

Questions

Is the free version limited in any way?

No. There is no trial, no locked feature and no nag. Every assistant, every layout, every notification and the whole cost breakdown are in the free app, and the source is on GitHub under MIT.

When can I actually buy Teams?

It isn't built yet. The design is written up in the repository's roadmap — the privacy model, the document shape and what the dashboard shows — and the waitlist is how it gets prioritised. If enough budget owners want it, it gets built; if they don't, Notchmeter stays an excellent personal tool, which is a fine outcome too. You will not be charged for anything before it exists.

Why $6 a seat?

Because of what it sits next to. Claude Code alone runs roughly $150–250 per developer per month, so a roll-up across every vendor at $6 is between two and four per cent of the spend it governs — small enough to approve without a meeting, which is the only price a tool like this can be.

Do I have to send you anything to use Teams?

No. The server is a single binary with a SQLite file that you run, or you can point the client at a bucket you own and run no server at all. A hosted version, if there ever is one, is the same binary run by us with the same document — nothing extra is collected because there is nowhere for it to come from.

Will Teams see what my engineers are working on?

It cannot. It receives one aggregate a day per machine: usage fractions, reset times and a cost estimate. There is no prompt, no transcript, no repository name and no timestamp finer than the day, and each machine's sharing is opt-in and off until someone turns it on. The panel says so on screen while it is on, and Settings shows the last seven documents verbatim.

Does it work if I only use one assistant?

Yes — turn the others off in Settings and the strip shows what's left. The cross-vendor view is where Teams earns its keep, though: Anthropic and Cursor both have admin dashboards for their own numbers, so a roll-up is only worth paying for across vendors and on pace.

Can I support the project without a team?

GitHub Sponsors, on the repository. It is genuinely optional and the app will never ask you for it.
